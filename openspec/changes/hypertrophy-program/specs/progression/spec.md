## ADDED Requirements

### Requirement: Рекомендации по ступеням
Рекомендации SHALL формироваться только для завершённой или остановленной сессии — по одной на каждое упражнение — и касаются только ступени сопротивления.
Во время активной тренировки ступень MUST NOT меняться.
Диапазон повторов упражнения MUST NOT меняться рекомендациями.

#### Scenario: Активная сессия
- **WHEN** сессия ещё идёт
- **THEN** рекомендаций нет

### Requirement: Двойная прогрессия
Для каждого упражнения правила SHALL применяться по порядку, срабатывает первое подходящее:
1. В самооценке отмечена боль, либо любое упражнение сессии пропущено из-за боли → для всех упражнений сессии повышение ступени запрещено: решение «ступень выше» заменяется на «Без повышения», правило «ниже диапазона → ступень ниже» продолжает действовать.
2. Упражнение пропущено по другой причине → ступень не меняется.
3. По упражнению нет ни одного подхода → ступень не меняется.
4. Первый подход ниже нижней границы диапазона → ступень ниже; на первой ступени — совет выполнять сколько получается без изменения ступени.
5. Хорошая техника не подтверждена ответом на вопрос о технике (ответ «нет» или нет ответа) → ступень не меняется.
6. Все запланированные подходы выполнены, и в каждом повторов не меньше верхней границы диапазона → ступень выше; на последней ступени — совет замедлить темп или добавить паузу без изменения ступени.
7. Иначе → «Добавляйте повторы», ступень не меняется.

Для остановленной сессии решение «ступень выше» MUST заменяться на «Без повышения».
RPE сессии MUST NOT влиять на решение.
Решение SHALL приниматься относительно ступени, записанной в тренировке, а не текущей ступени упражнения.

#### Scenario: Верх диапазона во всех подходах
- **WHEN** приседания на L2 (8–12): 12, 12, 13 повторов, техника хорошая
- **THEN** предлагается ступень L3

#### Scenario: Внутри диапазона
- **WHEN** приседания на L2: 12, 11, 10 повторов, техника хорошая
- **THEN** ступень не меняется, решение «Добавляйте повторы»

#### Scenario: Ниже диапазона
- **WHEN** отжимания от пола (6–12): первый подход 4 повтора
- **THEN** предлагается ступень «от стула»

#### Scenario: Высокий RPE не мешает прогрессу
- **WHEN** все подходы на верхней границе, техника хорошая, RPE 9
- **THEN** предлагается ступень выше

#### Scenario: Боль при лёгкой нагрузке
- **WHEN** все подходы на верхней границе, но отмечена боль
- **THEN** ни для одного упражнения повышение не предлагается

#### Scenario: Пропуск одного упражнения из-за боли
- **WHEN** одно упражнение пропущено из-за боли, остальные выполнены на верхней границе диапазона
- **THEN** ни для одного упражнения сессии повышение не предлагается

#### Scenario: Вопрос о технике без ответа
- **WHEN** все подходы на верхней границе, но тренировка остановлена на вопросе о технике
- **THEN** повышение для этого упражнения не предлагается

#### Scenario: Техника страдала
- **WHEN** тренировка завершена, все подходы на верхней границе, на вопрос о технике ответ «нет»
- **THEN** ступень не меняется

#### Scenario: Боль и подходы ниже диапазона
- **WHEN** отмечена боль, а первый подход отжиманий от пола — 4 повтора
- **THEN** предлагается ступень «от стула»

#### Scenario: Последняя ступень
- **WHEN** разведения рук на L2 (последняя ступень): все подходы по 20 повторов
- **THEN** ступень не меняется, предлагается замедлить темп или добавить паузу

### Requirement: Подтверждение смены ступени
Рекомендация со сменой ступени SHALL применяться только после того, как пользователь нажмёт «Принять»; «Оставить как есть» отклоняет её.
Завершение тренировки само по себе MUST NOT менять ступень.
Рекомендация по упражнению, по которому в новой тренировке записан хотя бы один подход, SHALL заменять прежнюю непринятую; если подходов не было, прежняя непринятая рекомендация сохраняется. Рекомендация, у которой текущая ступень уже не совпадает с фактической, MUST NOT показываться и MUST NOT применяться.
После остановленной сессии или сессии с болью все непринятые рекомендации повысить ступень MUST сниматься, в том числе по упражнениям другой тренировки.

#### Scenario: Без подтверждения
- **WHEN** пользователь завершил тренировку с рекомендациями и не принял их
- **THEN** ступени упражнений остались прежними, а на главной показаны ожидающие рекомендации

#### Scenario: Упражнение не дошло до выполнения
- **WHEN** после тренировки A ожидает рекомендация для отжиманий, а в тренировке B отжимания пропущены
- **THEN** рекомендация для отжиманий по-прежнему ожидает подтверждения

#### Scenario: Боль после ожидающих рекомендаций
- **WHEN** после тренировки B остались непринятые рекомендации повысить ступень, а на следующей тренировке A отмечена боль
- **THEN** рекомендации повысить ступень для упражнений B больше не показываются

### Requirement: Ручной выбор ступени
Пользователь SHALL иметь возможность вручную выбрать любую ступень упражнения в библиотеке.
Ручное изменение SHALL удалять ожидающие рекомендации по этому упражнению.

#### Scenario: Ручной выбор ступени
- **WHEN** пользователь выбирает для тяги в наклоне ступень L2+L3
- **THEN** следующая тренировка B показывает тягу с двумя лентами

## REMOVED Requirements

### Requirement: Когда формируются рекомендации
**Reason**: Рекомендации больше не сравнивают уровень с плановой неделей; заменено требованием «Рекомендации по ступеням».
**Migration**: См. «Рекомендации по ступеням».

### Requirement: Порядок правил
**Reason**: Правила по уровням недели и RPE заменены двойной прогрессией по ступеням сопротивления.
**Migration**: См. «Двойная прогрессия».

### Requirement: Явное подтверждение
**Reason**: Подтверждение теперь относится к смене ступени, а не уровня, ленты и замены упражнения; симптомы сведены к боли.
**Migration**: См. «Подтверждение смены ступени».

### Requirement: Ручное изменение
**Reason**: Уровень, лента и замена упражнения объединены в одну ступень сопротивления.
**Migration**: См. «Ручной выбор ступени».

### Requirement: Ограничения по лентам
**Reason**: Ограничение L3 и правило «L2 только для приседаний и моста» относились к реабилитационной программе; ленты теперь — обычные ступени сопротивления.
**Migration**: Допустимые ленты для упражнения определяются его лестницей ступеней в `exercise-library`.
