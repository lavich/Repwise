## 2. Анимация

- [ ] 2.1 Модель позы: ломаная — одна часть тела с `kind` (`torso`/`arm`/`leg`), `active`, необязательной привязкой `attach`; голова, концы лент и реквизит привязаны к точкам тела; `tempo` у кадров; перевести позы 15 упражнений (в отжиманиях разделить ногу и корпус, полотенце привязать к пятке). Проверка: тест — у `start` и `end` одинаковые ломаные, `kind`, число точек, ленты и реквизит; у `leg` 3–4 точки, у `arm` 3.
- [ ] 2.2 Чистые функции угловой интерполяции позы и фазы цикла по времени (`poseAt(frames, ms)`). Проверка: тесты — в 0 мс поза равна `start`, в конце перехода — `end`; при t = 0,25 / 0,5 / 0,75 длина каждого сегмента в пределах длин в крайних кадрах ±10 % для всех 15 упражнений; цикл повторяется; через 5 циклов фаза — остановка.
- [ ] 2.3 Рендер объёмной фигуры: сегменты по толщинам design §2, `active` — цветом мышц, дальние конечности приглушены. Проверка: скриншоты 15 упражнений на 390 px в тёмной и светлой темах.
- [ ] 2.4 Компонент анимации: `requestAnimationFrame` с записью в SVG через ссылки, работа только на видимом экране (`IntersectionObserver`, `visibilitychange`), подпись фазы, кнопка «Пауза»/«Запустить»/«Повторить» рядом с SVG (`role="img"` только на SVG), подписка на `prefers-reduced-motion`. Проверка (вручную через браузерный инструмент Playwright, в проекте его нет): на приседаниях кадр меняется со временем, после «Пауза» не меняется, после прокрутки за пределы экрана не меняется; `getByRole('button', { name: 'Пауза' })` находится; с `reducedMotion: 'reduce'` видны «Начало» и «Конец».
