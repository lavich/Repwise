- [ ] 2.1 Зависимость `three`; таблица `MODELS` для отжиманий и приседаний; чистые функции: уровни 16 групп по мышцам упражнения, время клипа по `t`, выбор трёхмерного показа. Проверка: юнит-тесты.
- [ ] 2.2 Общий хук цикла анимации (пауза, «Повторить», видимость), плоская анимация переведена на него. Проверка: существующие проверки плоской анимации проходят.
- [ ] 2.3 Ленивый трёхмерный компонент по design §4. Проверка (вручную через Playwright): на отжиманиях кадр меняется, пауза останавливает, перетаскивание поворачивает, вертикальная прокрутка работает; при заглушке `getContext → null` — плоская анимация; при `reducedMotion: 'reduce'` модель неподвижна; при смене темы цвета меняются; у тяги сидя — плоская анимация.
- [ ] 2.4 `glb` в предкэше. Проверка: `BASE_PATH=/Repwise/ npm run build` — `models/mannequin.glb` в списке предкэша, модель открывается в `vite preview` с этим базовым путём.
- [ ] 2.5 Вес: начальный чанк +≤ 5 КБ gzip, ленивый чанк ≤ 200 КБ gzip. Проверка: сравнение `npm run build` до и после.
