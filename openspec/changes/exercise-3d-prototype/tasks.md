## 1. Модель

- [ ] 1.1 `tools/blender/fetch_sources.sh`: скачать модель и анимацию отжиманий Mesh2Motion по закреплённой ревизии во временную папку. Проверка: скрипт завершается с кодом 0, файлы на месте.
- [ ] 1.2 `tools/blender/build_mannequin.py`: импорт, анимация приседаний (IK стоп, запекание), разметка мышц в `_MUSCLE`, экспорт GLB с двумя клипами. Проверка: рендеры отжиманий и приседаний (начало, середина, конец) и раскраски мышц спереди и сзади просмотрены; размер GLB ≤ 1,5 МБ.
- [ ] 1.3 `tools/blender/README.md`: как пересобрать модель, источник и лицензия. Проверка: прочитано.

## 2. Приложение

- [ ] 2.1 Зависимость `three`; поле `model3d` у отжиманий и приседаний. Проверка: `npx tsc -b`; прирост JS ≤ 200 КБ gzip по `npm run build`.
- [ ] 2.2 Компонент трёхмерного показа: загрузка GLB, материал с подсветкой мышц по токенам темы, анимация по `cycleAt`, пауза/«Повторить», остановка вне экрана, неподвижная модель при уменьшении движения, вращение перетаскиванием, лента линиями, откат к плоской анимации без WebGL или при ошибке загрузки. Проверка (вручную через Playwright): на отжиманиях кадр меняется, пауза останавливает, перетаскивание поворачивает, у тяги сидя — плоская анимация.
- [ ] 2.3 Подключить в `ExerciseIntro`, окне «Техника» и библиотеке; GLB в предкэше service worker. Проверка: `npm run build` — `mannequin.glb` в списке предкэша.
- [ ] 2.4 Тест на данные: у каждого упражнения с `model3d` клип есть в списке клипов модели. Проверка: `npx vitest run`.
