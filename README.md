# Repwise

Личное PWA-приложение для 4-недельной программы домашних тренировок (ноги и кор): щадящий вводный блок без нагрузки на верх тела, без резких движений головой и смены положения тела.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # типы, линтер, тесты, сборка
npm run build && npm run preview -- --host   # продакшен-сборка с service worker
```

Иконки генерируются из `public/favicon.svg`: `npm run icons`.

## Установка на iPhone

1. Опубликуйте `dist/` на любом статическом HTTPS-хостинге (Netlify, Vercel, Cloudflare Pages, GitHub Pages). Service worker работает только по HTTPS или на `localhost`.
2. Откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
3. Запустите приложение с экрана «Домой» хотя бы раз онлайн — после этого оно работает офлайн.

Данные хранятся только в `localStorage` на устройстве. Делайте резервную копию: «Настройки» → «Экспорт в JSON».

## Структура

```
src/
  domain/      типы, упражнения, программа A/B, сессия, прогрессия, ход тренировки, статистика (+ тесты)
  storage/     схема zod, localStorage, экспорт/импорт JSON (+ тесты)
  state/       хранилище (useSyncExternalStore) и действия
  components/  UI-примитивы в стиле shadcn, SVG-иллюстрации, графики, календарь
  screens/     главная, тренировка, библиотека, прогресс, настройки, итог
```
